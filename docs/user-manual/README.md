# Guida all’utilizzo della piattaforma

Questa documentazione descrive il funzionamento della piattaforma e le principali operazioni disponibili per la gestione di **Utenti, Locations, Aree e Records**.

---

## Indice

### Gestione Base

- [**Utenti**](UTENTI.md) - Creazione, modifica ed eliminazione degli utenti (solo Amministratori)
- [**Locations**](LOCATIONS.md) - Gestione delle sedi/locations
- [**Aree**](AREE.md) - Gestione delle aree di stoccaggio
- [**Records**](RECORDS.md) - Gestione completa dei dischi (creazione, import/export, eliminazione)

### Vendite e Transazioni

- [**Vendite**](VENDITE.md) - Gestione delle vendite al dettaglio
- [**Carichi**](CARICHI.md) - Gestione carichi da fornitori (wholesale in)
- [**Scarico e Backorder**](SCARICO_BACKORDER.md) - Gestione scarichi e ordini arretrati (wholesale out)

### Gestione Contenuti

- [**Formati**](FORMATI.md) - Gestione dei formati musicali (LP, CD, ecc.)
- [**Artisti**](ARTISTI.md) - Gestione degli artisti
- [**Etichette**](ETICHETTE.md) - Gestione delle etichette discografiche
- [**Clienti**](CLIENTI.md) - Gestione dei clienti
- [**Fornitori**](FORNITORI.md) - Gestione dei fornitori

### Integrazione Marketplace

- [**Discogs**](DISCOGS.md) - Sincronizzazione automatica ordini dal marketplace
- [**Discogs: Release ID e Listing ID**](DISCOGS_IDS.md) - Differenza tra i due identificativi, dove vengono salvati e cosa inserire
